# Game-211-MIDSTONE-Absurd-Hoops
Midstone Final for Game-211, "Absurd Hoops" 

## Upon loading the title screen, press the "1" key to load into the level 
# Controls
"G" - increase ball power
"H" - decrease ball power
"O" - increase launch angle
"P" - decrease launch angle
"R" - reset ball
"E" - spawn ball
"Space" - launch ball
