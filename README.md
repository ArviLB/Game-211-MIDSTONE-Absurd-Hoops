# Game-211-MIDSTONE-Absurd-Hoops
Midstone Final for Game-211, "Absurd Hoops" 

### The game only features a title screen and one level. The goal is to shoot the bowling ball into the basketball hoop underwater, just be careful of breakable crates and rocks. How absurd!

# Controls
## Upon loading the title screen, press the "1" key to load into the level 

"G" - increase ball power

"H" - decrease ball power

"O" - increase launch angle

"P" - decrease launch angle

"R" - reset ball

"E" - spawn ball

"Space" - launch ball

"Alt + F4" - Close the program
